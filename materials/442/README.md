计量约定

本题的逻辑检索payload单位按一次实际读取的索引项计：trie节点或弧计1单位，其中弧记录自带的单码点label属于该弧字段，不再重复加1。若另行读取独立字符数组或词项字符串，则按实际访问码点计；同一内容再次读取仍计。不能把包含整个词库的数组/JSON一次性加载后只报搜索过程中碰到的少数字符。

完整term业务记录另按读取记录数统计，包含候选失败和库内部完整词扫描。索引构建单独计量；公开基准用重新打开索引且无查询结果缓存的冷查询。SQLite底层B树页与OS缓存不属于上述逻辑索引项，但实际读取字节另报。若成熟库隐藏内部访问，使用可审计的保守上界，不把未知数写0。

benchmark.py只生成输入与查询；不提供目标检索实现。内部审稿可行性探针不在本题材料中。
